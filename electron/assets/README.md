# 应用图标目录

请将以下图标文件放在此目录：

## Windows
- **icon.ico** - 256x256 像素
- 生成工具：https://iconvert-icons.com/

## macOS
- **icon.icns** - 多尺寸图标集
- 生成工具：https://iconvert-icons.com/

## Linux
- **icon.png** - 512x512 像素
- 可以使用任何 PNG 图片

## 推荐工具

1. **在线转换**
   - https://www.electronjs.org/docs/latest/tutorial/icon
   - https://iconvert-icons.com/

2. **本地工具**
   - GIMP (免费)
   - Photoshop
   - Icon Slayer

## 图标设计要求

- 简洁明了
- 辨识度高
- 背景透明
- 适合小尺寸显示

生成图标后，删除此文件。
